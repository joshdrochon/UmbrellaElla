# Decisions

Two tables. **Open decisions** are real tradeoffs a named person must choose. **Settled rules** are former rows that
are now written rules or defaults; their IDs stay so old references still resolve.

Agents never decide an open row, except a 2 h grace default (`pipeline/human-checkpoints.md`). Until a row says DECIDED, build its "Default until decided" and name the row in the PR.
New rows in a PR use the ID `D-new-<card id>`; the Producer gives them a number on merge.
`python3 tools/pipeline_check.py` fails when a doc cites an ID with no row here, or an owner is not a People seat in
`docs/jam-brief.md`.

Rules for deciding:
- The owner edits the row from their own GitHub account: Status `DECIDED <date> (<name>)`, the option rejected, and the evidence (PR, playtest row or quote).
- A row with a Proposed test goes DECIDED only after its result is posted.
- Grace default: a needs-human item no human answered in 2 h gets a new row with Status `DECIDED <YYYY-MM-DD> (agent default after 2h grace; <Producer | Technical Director | Producer for Richard>; human may overturn)` and a link to the needs-human issue. Never on a human-only kind (`pipeline/human-checkpoints.md`), never with `Overrides:`, never an `approved_parameters` range (`manifest_check.py` grace). A later human answer wins and gets its own row.
- A DECIDED row lifts the P0-on, never-cut and BASE-ships rules only for the IDs it lists in an `Overrides: <IDs>` clause (e.g. `Overrides: DEF-01, T-03`). Naming an ID anywhere else in the row lifts nothing (`manifest_check.py`, `bake_preset.py`, `check_card.py`). The row counts only in the Open decisions table, with Status exactly `DECIDED <YYYY-MM-DD> (Richard)` (GDD 1.3 §14: Richard approves P0 status and presets), a named Owner, and no SUPERSEDED anywhere in it. Any other DECIDED row with `Overrides:` fails `manifest_check.py`. Overrides never turn on a feature the GDD says is OFF or that is not approved.
- A DECIDED row is reopened only by a new row that cites a new measurement or playtest. Disagreement alone does not reopen it.
- A row decided again is marked `SUPERSEDED by D<n>`. It is never deleted.
- Ties on look, feel or theme go to the Creative director (D34). Ties on scope go to the Scope decision-maker.
- "Blocks" says what cannot start until the row is decided or its default is accepted: `Nov 11` (theme day), `Nov 12` (first game work), a gate, or `–`.
